Cube Case Editor

Build a Case.

Click stickers to paint colors, export themeable SVG.

How to use: Pick a color, click stickers to paint. Name your case (e.g. pi, sune) and download. Save to your repo's images/ folder.

⚠️ Themeable note: Themed SVGs only inherit theme colors when inlined into the HTML — not via <img> tags (those sandbox the SVG). The main cheatsheet uses a small loader script that fetches the SVG and injects it inline, so themes will work. If you ever use the SVG outside that setup, choose Hardcoded mode.
